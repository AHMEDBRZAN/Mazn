# فاتورة المورد ← ملف استيراد سراج (نسخة القراءة المطابقة)

## ما الجديد في القراءة
- **3 قراءات نصية مستقلّة** (تباين مضبوط / Otsu / إضاءة موضعية Adaptive) + **قراءة أرقام مخصّصة** بمحرك إنجليزي وقائمة رموز رقمية فقط.
- **كشف أعمدة الكمية/السعر/المبلغ هندسياً** من إحداثيات الكلمات، مع اختبار اتجاهين واختيار الأصلح حسابياً.
- **تصحيح المعرفات والباركود من الكتالوج**: أي رقم يُطابق كود/باركود صنف (أو يبعد عنه خانة واحدة) يُثبَّت عليه — يقين 100%.
- **حلّ حسابي للأرقام المتشابهة** (0/8/6، 1/7، 5/6…): يجرّب البدائل ويشترط كمية×سعر=إجمالي، ويرجّح سعر الكتالوج عند تطابق الاسم.
- **تصويت بين القراءات** لكل خلية، وشارة حالة لكل سطر (مؤكد / مصحّح / شك / يدوي) مع عرض القراءات الأصلية والتصحيحات بالضغط عليها.
- **تقرير تدقيق JSON** قابل للتنزيل يسجل كل قراءة وكل تصحيح.
- قائمة الشركة تعرض **المجموعات والشركات معاً** مع عدد الأصناف، وبحث فوري.

## التشغيل
ارفع `index.html`, `style.css`, `app.js`, `README.md` ومعها `catalog.json` كما هو في جذر المستودع، ثم فعّل GitHub Pages (main / root). أول تشغيل يحتاج إنترنت لتحميل نموذج العربية؛ بعدها كل المعالجة داخل الجهاز.

## قواعد الأمان
أي شك يوقف العملية. لا يُصدَّر ملف إلا بعد: حساب كل سطر صحيح + مجموع الأسطر = مجموع الورقة + تأكيد يدوي صريح + حسم كل ربط.
