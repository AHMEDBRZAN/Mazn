# فاتورة المورد ← ملف استيراد سراج

أداة ويب (تعمل من الهاتف) تحوّل فاتورة المورد الورقية إلى ملف استيراد لسراج:
1. اختيار الشركة ثم تصوير الفاتورة (تدعم عدة صفحات).
2. قراءة OCR مزدوجة مستقلة (معالجة صورتين مختلفتين + وضعي تقسيم مختلفين) وفحص حسابي (كمية×سعر=إجمالي، ومجموع الأسطر=مجموع الفاتورة). أي شك يوقف العملية.
3. مطابقة تلقائية مع أصناف الشركة، والأسطر الغامضة (مثل «جميع الألوان») تُوزَّع يدوياً بحيث يساوي المجموع كمية الورقة تماماً.
4. تنزيل ملف الاستيراد بنفس بنية `catalog.json` (hdr/fields/base/vary + سجلات v ثنائية) مع حقن الكمية والسعر والإجمالي، plus CSV احتياطي.

## التشغيل على GitHub Pages
1. ارفع الملفات: `index.html`, `style.css`, `app.js`, `README.md`، وارفع `catalog.json` كما هو بجانبها في جذر المستودع.
2. Settings → Pages → Branch: main / root → Save.
3. افتح الرابط الناتج من الهاتف. أول تشغيل يحتاج إنترنت لتحميل نموذج العربية (~2MB)، وبعدها المعالجة كلها داخل الجهاز.

## ملاحظات مهمة
- يدعم المطبوع فقط؛ الخط اليدوي أو الثقة المنخفضة يوقفان العملية.
- بنية ملف الاستيراد مبنية على نفس ترميز كتالوج سراج المرفق (تم فك ترميز v بالكامل). جرّب استيراد فاتورة واحدة أولاً للتأكد؛ إن كان لدى سراج نموذج استيراد رسمي مختلف، أرسله ليُضبط المولّد عليه.
- لا تُرفع الصور أو البيانات لأي خادم.
